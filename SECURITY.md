# Security Policy

## Supported Versions

Currently, the primary branch (`main`) is the only supported version receiving security updates.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| earlier | :x:                |

## Reporting a Vulnerability

Security and privacy are core to Infyn's mission. Since Infyn processes all data locally in the browser (zero uploads), many common backend vulnerabilities are naturally mitigated. However, we take all potential client-side vulnerabilities, dependency flaws, and XSS risks very seriously.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them directly by reaching out to the maintainers privately (or opening a GitHub Security Advisory draft if applicable). 

Please include the following information in your report:
- A description of the vulnerability and its impact.
- Steps to reproduce the issue.
- Any potential fix or mitigation if you have one.

We will acknowledge your report as quickly as possible and work to resolve the vulnerability before it is publicly disclosed. Thank you for helping keep Infyn secure and private for everyone!
